# モード：model（モデル選択アドバイス）

タスクの種類に応じた最適モデルをガイドする。

## Claude Codeで利用できるモデル

| モデル | 特徴 | コスト感 |
|--------|------|----------|
| **Haiku** | 高速・軽量。単純なタスク向け | 最安 |
| **Sonnet** | バランス型。デフォルト推奨 | 中 |
| **Opus** | 高精度。日常の複雑な作業の第一候補 | 高 |
| **Fable** | 最上位モデル。長時間・高難度のエージェント作業向け | 最高 |

> Fable は安全分類器により一部のリクエストを断る場合がある。断られたら Opus に切り替える。
>
> バージョン番号はモデル更新で変わるため記載しない。最新のモデル名・ID は `/model` コマンドまたは公式ドキュメントのモデル一覧で確認する。

## 出力

以下のガイドを表示し、末尾でタスクを尋ねる：

```
## タスク別モデル選択ガイド

### Haiku を使うとき（コスト優先）
✅ 短いコードの補完・修正 / ファイルの整形
✅ 繰り返し作業・単純なQ&A・コマンド確認
✅ ログやエラーメッセージの要約

### Sonnet を使うとき（デフォルト・バランス）
✅ 中規模の機能実装・バグ調査
✅ コードレビュー・リファクタリング
✅ ドキュメント・テストコード作成

### Opus を使うとき（品質優先）
✅ 複雑なアーキテクチャ設計・技術選定
✅ 難解なバグの根本原因分析・大規模リファクタリング
✅ セキュリティレビュー・未知領域の調査

### Fable を使うとき（最高性能・高コスト）
✅ 長時間かかる自律的なエージェント作業（大規模な移行・多段階の実装）
✅ Opus で解けなかった高難度の技術課題
⚠️ 日常作業は Opus で十分。コスト差が大きいため常用しない
```
