# モード：audit（CLAUDE.md 監査）

セッション開始時に常時読み込まれるファイル群を診断し、肥大化箇所の削減を提案する。

## 手順

1. 以下の監査対象を存在するものだけ読み込む
2. プロジェクトの `CLAUDE.md`（`./CLAUDE.md` と `./.claude/CLAUDE.md` のどちらも）が無い場合 → 下記「新規作成」へ分岐
3. 診断観点に沿って診断し、出力フォーマットで結果を表示する

## 監査対象

| 種別 | パス |
|------|------|
| グローバル | `~/.claude/CLAUDE.md`（Windows: `%USERPROFILE%\.claude\CLAUDE.md`） |
| プロジェクト | `./CLAUDE.md`、`./.claude/CLAUDE.md` |
| ローカル（個人用） | `./CLAUDE.local.md` |
| インポート先 | 上記ファイル内の `@path/to/file` で参照されるファイル |
| サブディレクトリ | `**/CLAUDE.md`（一覧と行数のみ。該当ディレクトリ作業時に読み込まれる） |
| 自動メモリ | `~/.claude/projects/<プロジェクト>/memory/MEMORY.md`（存在する場合） |

## トークン数の見積もり

- 実測が必要なら `/context` の実行をユーザーに案内する（メモリファイルの消費量が表示される）
- 概算は「日本語 1文字 ≈ 1トークン、英数字 4文字 ≈ 1トークン」で計算し、「概算」と明記する

## 診断観点

| カテゴリ | 効率化推奨の内容 |
|----------|--------------|
| AIが既知の情報 | 一般的なベストプラクティス・コーディング規約 |
| 歴史・経緯 | 「以前は〜だったが」「〜という経緯で」 |
| 過剰な説明 | 1行で書けるルールに3行以上かけている箇所 |
| 重複 | 同じルールが複数ファイル・複数箇所に書かれている |
| 常時不要 | 特定作業でしか使わない詳細（→ 別ファイル化してリンクのみ残す） |

## 出力フォーマット

診断結果と、番号付きの修正案（差分）を同時に表示する：

```
## CLAUDE.md 監査結果

| ファイル | 行数 | 概算トークン |
|---------|------|------------|
| ~/.claude/CLAUDE.md | XX | 約XXX |

### 修正案
1. [~/.claude/CLAUDE.md 行XX-XX] AIが既知
   - 前: 「〜」
   - 後: （削除）
2. [./CLAUDE.md 行XX-XX] 1行に圧縮
   - 前: 「〜」
   - 後: 「〜」

推定効果: 約XXXトークン → 約XXXトークン（XX%軽量化）

適用する番号を入力してください（例: 1 3 / 全部: all / やめる: skip）
```

番号の入力を同意とみなし、該当箇所を Edit ツールで書き換える。完了後、変更したファイルと削減トークン数を1〜2行で報告する。

---

## 新規作成（プロジェクト CLAUDE.md 不在時）

1. カレントディレクトリの構成を Glob で確認し、言語・フレームワーク・用途を推定する
2. 以下を1回で確認する：

```
プロジェクトの CLAUDE.md が見つかりません。
推定プロジェクト種別: （例: Python CLI / Node.js API / Flutter アプリ）

  1. /init で自動生成（推奨）→ Claude Code がコードベースを解析して作成します
  2. テンプレートから作成 → 下記テンプレートを推定内容で埋めます
  3. 最小構成 → コマンドのみ記載します
  4. 作成しない（skip）

番号を入力してください：
```

- **1**：ユーザーに `/init` の実行を案内して終了する（スキルからは実行できないため）
- **2 / 3**：ドラフトを表示し「OK / 修正点」を確認、OK でカレントディレクトリに `CLAUDE.md` を書き出す

### テンプレート（選択肢 2）

````markdown
# CLAUDE.md

## プロジェクト概要
（1〜2行でプロジェクトの目的・用途を記述）

## 技術スタック
- （言語・フレームワーク・主要ライブラリ）

## よく使うコマンド
```bash
# ビルド
# テスト
# 起動
```

## 重要なルール・制約
- （禁止事項・命名規則・フォルダ構成など）
````

### 最小構成（選択肢 3）

```markdown
# CLAUDE.md

## コマンド
（ビルド・テスト・起動コマンドのみ）
```
