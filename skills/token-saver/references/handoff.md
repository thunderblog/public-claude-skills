# モード：handoff（セッション引き継ぎ）

現在の会話コンテキストを要約し、次のセッションにそのまま引き継げるドキュメントを生成してファイルに保存する。

## 保存先パスの決定

- `/token-saver handoff [パス]` のように引数があればそのディレクトリを使う
- 指定がなければ `tasks/` を使う
- ファイル名は `handoff-YYYY-MM-DD.md`

## 出力フォーマット

```
## セッション引き継ぎ（{日付}）

### 現在取り組んでいるタスク
- （今やっていること）

### 完了済み
- （完了したこと）

### 次にやること
- （次のステップ）

### 重要な決定事項
- （このセッションで決まったこと）

### 関連ファイル・パス
- （作業中のファイルパスなど）

### 引き継ぎメモ
（注意点・文脈・前提など）
```

## 生成後のフロー

**確認（1回）** — サマリーと保存先をまとめて提示する：

```
上記の引き継ぎサマリーを以下に保存します。
  {保存先パス}/handoff-YYYY-MM-DD.md

保存する（OK）/ 内容を修正（修正点を入力）/ 別のパスに保存（パスを入力）/ 保存しない（skip）
```

- 修正点が入力されたらサマリーを直して同じ確認を再表示する
- `skip` ならサマリー表示のみで終了する

**同名ファイルがある場合のみ** — 上書き確認：

```
同じ日付のファイルが既に存在します: {ファイルパス}
  1. 上書きする  2. 別名で保存（handoff-YYYY-MM-DD-2.md）  3. キャンセル
```

**保存実行** — Write ツールで書き出し、以下を表示する：

```
引き継ぎファイルを保存しました: {保存したパス}

次の手順でコンテキストをリセットして再開できます：
  1. /clear を実行（会話コンテキストを破棄）
  2. /token-saver load {保存したパス} で読み込み
```
