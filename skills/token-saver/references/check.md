# モード：check（コスト効率化チェックリスト）

即行動できる対策を表示する。

```
## ClaudeCode コスト効率化チェックリスト

1. 今のコンテキスト量を確認する
   → /context で消費内訳、/cost でセッションのコストを確認できます。

2. セッションをリセットする
   → 話題が変わったら /clear。続きが必要なら先に `/token-saver handoff` で引き継ぎを保存。

3. 会話を圧縮する
   → 同じ作業を続けるなら /compact <残したい内容>（例: /compact 決定事項と未解決のバグだけ残す）。

4. CLAUDE.md をスリムに保つ
   → 毎セッション読み込まれるため、肥大化はそのままコスト増になります。`/token-saver audit` で診断。

5. タスクに合ったモデルを選ぶ
   → 単純作業は軽量モデルで十分。`/token-saver model` で選択ガイドを表示。

実行する番号を入力してください（例: 2 / 複数: 2 4 / やめる: skip）：
```

## 番号選択後の動作

番号の入力を実行の同意とみなし、再確認しない。

| 番号 | 動作 |
|------|------|
| 1 | `/context`・`/cost` の実行を案内する（組み込みコマンドはユーザーが実行する） |
| 2 | handoff モードを実行（`references/handoff.md` を読む）。保存後に `/clear` を案内 |
| 3 | 現在の会話から残すべき内容を提案し、そのまま使える `/compact ...` コマンドを1行で提示 |
| 4 | audit モードを実行（`references/audit.md` を読む） |
| 5 | model モードを実行（`references/model.md` を読む） |
