# モード：load（引継書の読み込み）

保存済みの引き継ぎファイルを読み込み、前回セッションのコンテキストを復元する。

## ファイルの特定

- `/token-saver load [ファイルパス]` のように指定があればそのファイルを読む
- 指定がなければ Glob で `tasks/handoff-*.md` を検索する（`tasks/archive/` は対象外）

| 検索結果 | 動作 |
|---------|------|
| 0件 | 「引き継ぎファイルが見つかりませんでした。まず `/token-saver handoff` で作成してください。」と表示して終了 |
| 1件 | 確認なしでそのまま読み込む |
| 複数 | 日付降順で番号付き一覧を表示し、番号を選ばせる（やめる: skip） |

複数時の表示例：

```
引き継ぎファイルが複数見つかりました。読み込むファイルを選んでください：
  1. tasks/handoff-2026-04-18.md
  2. tasks/handoff-2026-04-15.md
番号を入力してください（やめる: skip）：
```

## 読み込み後の出力

Read ツールで読み込み、以下の形式で要約を表示する：

```
## 引き継ぎ内容を読み込みました（{ファイルパス}）

**取り組み中のタスク:** （要約）
**次にやること:** （要約）
**関連ファイル:** （一覧）

読み込んだ引き継ぎファイルを tasks/archive/ に移動しますか？（移動: OK / 残す: そのまま次の指示へ）
セッションを再開する準備ができました。何から始めますか？
```

## アーカイブ（OK の場合のみ）

削除はせず、`tasks/archive/` へ移動する（誤操作でも復元できるようにするため）。
Bash ツールで以下を実行する：

```bash
mkdir -p "tasks/archive" && mv "{ファイルパス}" "tasks/archive/"
```

移動先に同名ファイルがある場合は、末尾に `-2` などを付けて移動する。
完了後「tasks/archive/ に移動しました」と1行で表示する。
